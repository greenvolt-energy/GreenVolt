# GreenVolt GitHub Submission Checklist

## Before making the repository public

### Identity
- [ ] Correct SIH problem statement ID
- [ ] Correct team name
- [ ] Correct team members
- [ ] Correct guide

### Technical consistency
- [ ] Final DC-bus voltage decided
- [ ] All battery/controller/inverter specifications match the final bus
- [ ] No old 24 V/48 V contradictions
- [ ] MPPT method matches implementation
- [ ] Braking method matches implementation
- [ ] Dashboard labels match actual data

### Evidence
- [ ] Prototype photographs
- [ ] Wiring diagram
- [ ] BOM
- [ ] Component datasheets
- [ ] Test procedures
- [ ] Raw measurements
- [ ] Measurement graphs
- [ ] Calibration evidence
- [ ] Simulation files/results
- [ ] ESP32 code
- [ ] Dashboard screenshots
- [ ] Prototype video

### Data integrity
- [ ] Every result labeled measured/calculated/simulated/planned
- [ ] No fabricated readings
- [ ] No unsupported efficiency claims
- [ ] No motor rated power presented as generator output
- [ ] No theoretical output presented as measured output

### Security
- [ ] No Wi-Fi password
- [ ] No MQTT password
- [ ] No API key
- [ ] No cloud token
- [ ] No personal private information

### Final judge experience
- [ ] README can be understood in 2 minutes
- [ ] Architecture image is clear
- [ ] Evidence folder is easy to find
- [ ] Video link works
- [ ] All important documents open
