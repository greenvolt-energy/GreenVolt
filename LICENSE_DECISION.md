# License Decision

The repository is intended for public SIH review.

Before adding an open-source license, the team should decide what rights it wants to grant.

If the team wants others to freely use, modify and redistribute the code/design documentation, select an appropriate OSI-approved license.

If the team wants to keep the hardware design or documentation proprietary, do not add a permissive open-source license without reviewing the implications.

For SIH submission, public visibility does not automatically require an open-source license.
