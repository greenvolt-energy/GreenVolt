# Validation Status

This file is intentionally conservative.

## Current evidence categories

**Measured:** Add only after physical instrument verification.

**Calculated:** Use equations and stated assumptions.

**Simulated:** Use MATLAB/Simulink or another documented model.

**Planned:** Future experiment.

## Rule

Every graph in this repository should state its data type.

Example:

> Calculated wind power estimate — not experimentally validated.

or:

> Measured wind-generator output — bench test, instrument XYZ, date YYYY-MM-DD.
