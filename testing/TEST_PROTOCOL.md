# Prototype Test Protocol

## Before every test

1. Inspect frame and rotor.
2. Verify electrical connections.
3. Verify emergency shutdown.
4. Verify fuse/isolator.
5. Verify measurement instruments.
6. Record environmental conditions.
7. Photograph the setup.

## Solar test

Record irradiance, voltage, current and temperature.

Repeat at different conditions.

## Wind test

Record wind speed, RPM, voltage and current.

Use controlled wind where possible.

## Hybrid test

Operate solar and wind simultaneously and record bus voltage, battery current and load.

## Evidence

For each test store:
- date/time
- setup image
- instrument image
- raw CSV
- calculation
- graph
- conclusion
- limitations
