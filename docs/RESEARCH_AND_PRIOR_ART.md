# Research and Prior Art

The project documentation references prior work in:

- Hybrid solar-wind renewable-energy generators
- Domestic solar-wind hybrid systems
- Hybrid solar-wind energy towers
- Wind-solar tree concepts
- Commercial AeroLeaf-style vertical-axis wind systems
- Helical Savonius rotor studies
- IoT-monitored hybrid solar-wind systems
- National Wind-Solar Hybrid Policy

## Key takeaway

GreenVolt should not claim that hybrid solar-wind generation, VAWTs, MPPT, IoT monitoring or tree-based renewable systems are individually novel.

The project contribution should be described as the proposed integration of:
- tree-inspired architecture
- modular VAWT wind generation
- solar PV
- source-specific control
- common DC-bus integration
- storage
- braking/protection
- IoT monitoring
- serviceable modular construction
